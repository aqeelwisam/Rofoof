# رفوف — Android

A private, offline Android prototype for the three-shelf planning method.

## Build the APK

1. Open this folder in Android Studio.
2. Allow Gradle to sync and install Android SDK 35 if prompted.
3. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. The debug APK will be created under `app/build/outputs/apk/debug/`.

The app works offline. Tasks are saved locally on the Android device through WebView local storage.
